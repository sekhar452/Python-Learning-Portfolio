# Python Learning Portfolio

A structured collection of hands-on Jupyter notebooks covering Python fundamentals, data structures, functions, and object-oriented programming (OOP).

> **Purpose:** Learning portfolio and practice reference. Examples and topics reflect the notebooks in this repository; individual notebooks may need their dataset or execution environment configured before running.

## Topics Covered

| Section | Topics |
|---|---|
| **01 — Python Fundamentals** | Syntax and semantics, variables, data types, type casting, flow control, strings |
| **02 — Data Structures** | Lists, tuples |
| **03 — Functions** | Functions, recursive functions |
| **04 — Object-Oriented Programming** | Classes and objects, methods, variable types, method types, inheritance, polymorphism |

## Getting Started

### 1. Clone the repository

```bash
git clone <YOUR-REPOSITORY-URL>
cd Python-Learning-Portfolio
```

Replace `<YOUR-REPOSITORY-URL>` with the HTTPS URL of your GitHub repository.

### 2. Create and activate a virtual environment (recommended)

**Windows**
```bash
python -m venv .venv
.venv\Scripts\activate
```

**macOS / Linux**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install the notebook environment

```bash
pip install -r requirements.txt
```

### 4. Launch Jupyter

```bash
jupyter notebook
```

Then open the notebook you want to study and run the cells in order. Some examples may request input from the keyboard.
